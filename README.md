## 1.프로젝트 목적
##### : 흩어져있는 전국의 팝업스토어 정보를 한곳에서 탐색하고 실시간 예약까지 가능한 웹서비스


## 2.프로젝트 내용
##### '기존 소수 웹페이지의 가독성과 기능들로 인한 팝업 인지 및 예약 효율 저하' 문제점 발견
##### 이를 보완하기 위해
#####   - 편의성 : 복잡한 정보를 통합하여 한 곳에서 해결 가
#####   - 사용자 중심 : 맞춤형 정보를 제공하여 사용자에게 최적화된 정보 제공
#####   - 실시간 예약 : 예약관련 기능과 정보를 실시간으로 처리 및 확인 가능
#####   - 정보 소통 활성화 : 게시판 및 공지 기능을 통해 사용자 간 정보 소통 활성화

##### 5.프로젝트 결과 및 회고
######   ( 전체 결과 이미지 삽입 예정)
######  - 프로젝트 성과
######    완성도 70%
######    1. 전국 팝업스토어 정보를 한곳에서 탐색하고 예약할 수 있는 통합 플랫폼 구축
######    2. 카카오맵 API, 외부 데이터 연동, DB 설계 등 실제 서비스 구현 경험 확보
######    3. 회원가입, 로그인 및 SNS 로그인, 검색, 지도, 실시간 예약 및 결제, 게시판 등의 기능을 통해 사용자 편의성을 고려한 UI/UX 구현
######    4. 프론트엔드와 백엔드 전반에 참여하며 서비스 개발 프로세스 경험

######  - 한계점 및 개선 방향
######    직접 등록한 데이터만 서비스 반영 가능 → 크롤링 및 외부 API 연동을 통해 팝업 정보를 자동 수집·업데이트하는 기능 구현
######    프로젝트 기간의 제약으로 기능 구현 미완성 → 리뷰 조회·수정·삭제 기능을 추가하여 커뮤니티 기능 강화
######                                                 WebSocket 기반 실시간 관리자 문의 채팅 기능 구현

######  - 프로젝트를 통해 배운 점
######    1. 데이터 흐름과 서비스 구조를 함께 고려하는 개발의 중요성을 배움
######    2. 사용자 관점에서 기능을 설계하고 개선하는 문제 해결 능력을 향상시킴
######    3. API 연동 과정 → 데이터 가공 및 예외 처리의 필요성을 경험
######    4. DB 설계와 CRUD 구현 → 데이터 관리 구조에 대한 이해도를 높임
######    5. Git 협업 과정 → 브랜치 전략, 코드 병합 및 충돌 해결 경험을 쌓음
